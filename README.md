# 中南民大PPT辅助器

## 项目简介
中南民大PPT辅助器是一款基于Flask和python-pptx开发的在线PPT生成工具，帮助用户快速创建美观的演示文稿。

## 功能特性
- 支持多种PPT主题选择
- 在线编辑PPT内容
- 快速生成并下载PPT文件
- 响应式设计，支持各种设备访问

## 技术栈
- **后端**: Python + Flask
- **前端**: HTML, CSS, JavaScript
- **核心库**: python-pptx, Pillow

## 安装与运行

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行应用
```bash
python app.py
```

然后在浏览器中访问: http://127.0.0.1:5000

## 独立可执行文件
项目已使用PyInstaller打包为可执行文件，可在Releases中下载。

## 开发说明
- `app.py`: 应用主程序
- `templates/`: HTML模板
- `static/`: 静态资源
- `themes/`: PPT主题模板
- `uploads/`: 上传文件临时存储
